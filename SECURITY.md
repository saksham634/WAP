# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **Workforce Automation Portal (WAP)** seriously. If you believe you have found a security vulnerability, please do NOT open a public issue.

Instead, please report the vulnerability privately by emailing the repository owner or project maintainers.

### Reporting Guidelines
Please include the following details in your report:
- Type of issue (e.g., buffer overflow, SQL injection, unauthorized access, privilege escalation)
- Full paths to source file(s) related to the issue
- Step-by-step instructions or proof-of-concept to reproduce the issue
- Impact assessment and potential mitigations

We will review reports promptly and publish patches for confirmed security vulnerabilities.
